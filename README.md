# Түргэн Тоншуул

130-р сургуулийн 6-р ангийн Мэдээллийн технологийн сургалтын сайт: бичих дасгал (монгол, англи), онол, нэр томьёо, тоглоом, хурдны тест, нэгжийн шалгалт, багшийн самбар.

## Файлын бүтэц

```
index.html        — сайтын үндсэн хуудас (загвар, бүх үйлдэл)
logo130.png       — сургуулийн лого
data/typing.js    — бичих хичээлүүд (монгол 22, англи 20, нэмэлт дасгал)
data/theory1.js   — онолын хичээл, I бүлэг (1.1–1.2)
data/theory2.js   — онолын хичээл, II бүлэг (2.1–2.3)
data/terms.js     — нэр томьёо, командын сан
data/exams.js     — 5 нэгжийн шалгалтын сан (нэгж бүр 30 даалгавар)
```

## Компьютер дээрээ нээх

`index.html` файлыг Chrome эсвэл Edge хөтчөөр давхар товшиж нээнэ.

## GitHub Pages-д байршуулах

1. github.com дээр шинэ repository үүсгэнэ (жишээ нь `tonshuul`).
2. **Add file → Upload files** гэж ороод энэ хавтасны бүх файл, `data` хавтсыг чирж оруулна. Дараа нь **Commit changes** дарна.
3. **Settings → Pages** хэсэгт **Branch: main**, **/(root)** сонгоод **Save** дарна.
4. 1–2 минутын дараа `https://ТАНЫ-НЭР.github.io/tonshuul/` хаягаар сайт нээгдэнэ.

## Анхаарах зүйл

- Одоогийн хувилбар мэдээллийг тухайн компьютерын хөтөч дээр (localStorage) хадгална. Бүх сурагч, багш нэг мэдээллийг харахын тулд Firebase холбох шаардлагатай.
- «жишээ» гэсэн тэмдэгтэй сурагчид туршилтын өгөгдөл. `index.html` доторх `seed` хэсгийг устгавал алга болно.
